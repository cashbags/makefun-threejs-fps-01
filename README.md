EMBERLINE — Foundry 7: a complete round-based tactical FPS in three.js. 5v5 bomb plant/defuse on a three-lane industrial foundry map — Slag Lane, Furnace Hall, Mold Tunnel — with two bomb sites (Crucible and Casting Bay), a CS-style economy and buy menu, four weapons and three grenades, nine waypoint-driven bots that see, hear, burst-fire, plant and defuse, and a deterministic 60 Hz fixed-step simulation (seeded RNG, byte-identical replays).

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
